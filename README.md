# 信阳方言地理研究数据与代码

本仓库提供《基于方言地理学的方言分布格局及地理影响因素分析》相关的方言点来源信息、语音相似度矩阵、地理属性数据及部分分析代码，便于读者核查数据来源、了解计算方法并开展进一步分析。

研究语料涉及109个方言点，其中信阳市内83个、市外26个。语料来源表包含39个标注为“调查”的方言点和70个文献来源方言点。本次公开材料为整理后的矩阵、属性表、空间数据和源代码，不包含未经处理的原始音读库或录音。

### 系数及是否同一区域

每行代表一个不重复的方言点对：

- `城市1`、`城市2`：两个方言点名称。
- `系数`：点对的语音相似度。
- `历史`、`县界`、`河界`、`流域`：是否同属对应区域的二元编码，1表示同属，0表示不同属。

3403条记录来自83个点的两两组合，不应作为3403个彼此独立的采样点处理。同一方言点会参与多个点对。

## 空间数据

`行政区划.zip`包含历史县界、现行县界和现行市界三个图层。所附`.prj`声明的坐标参考系为WGS 1984地理坐标系，单位为度。使用时应保留同一图层的`.shp`、`.shx`、`.dbf`、`.prj`及其他配套文件，避免仅提取`.shp`。

部分解压软件可能将压缩包中的中文文件名显示为乱码，需要使用支持UTF-8文件名的解压方式。各图层的来源、适用年份及空间处理方法以论文与原始资料为准。

## 代码使用

### C++相似度量化

代码依赖Windows头文件和LibXL库。使用者需自行配置C++编译环境、LibXL头文件与链接库，并按其授权要求配置本地许可证。本公开副本已移除原代码中的硬编码软件授权信息。

运行前将`PATH`、`PATH2`分别改为输入音读表和输出矩阵的本地路径。输入音读表不在本次公开文件中，因此仅下载本仓库不能从原始音读重新生成全部矩阵。

所附版本筛选条件为`accsum <= 3`或`accsum >= changedata[0].size() - 3`。该参数是此份源代码的实际设置，使用者应据拟复现的实验版本核对，不应将其自动视为其他阈值实验的代码。

### Python轮廓系数与谱聚类

依赖`numpy`、`pandas`、`matplotlib`、`scikit-learn`、`openpyxl`；读取旧版`.xls`还需`xlrd`。原始环境版本未随文件提供，仓库不虚构锁定版本。

脚本保留作者原始实现：

1. 从Excel读取一个相似度矩阵；运行前须更改脚本中的本地输入与输出路径。
2. 候选簇数为2—10，谱聚类标签分配方式为`discretize`。
3. 根据候选轮廓系数的最大值选取簇数，再执行聚类并输出标签。
4. 通过t-SNE作二维展示。

原脚本没有自动提取市内83点，也没有自动递归执行三级聚类。研究市内分区时，应先提取83×83子矩阵；逐级分析时，再分别提取每个父簇内部的方阵进行计算。样本较少时，候选簇数必须小于样本量。

可用下面的示例读取总矩阵并提取83点，替换脚本原有的数据读取部分：

```python
import pandas as pd

full = pd.read_excel("相似度矩阵.xls", index_col=0, engine="xlrd")
df = full.iloc[10:93, 10:93].copy()
similarity_matrix = df.to_numpy(dtype=float)
assert similarity_matrix.shape == (83, 83)
assert list(df.index) == list(df.columns)
```

原脚本调用`silhouette_score(similarity_matrix, labels)`，计算的是将相似度矩阵各行当作特征向量时的欧氏距离轮廓系数，而不是以`1 − 相似度`为预计算距离的轮廓系数。二者口径不同，比较结果时须明确所用定义。

原脚本未固定随机种子，且选簇和最终标签输出时分别调用聚类，因此重复运行可能得到不同结果。若为复核设置固定`random_state`，应记录该设置，并同时记录候选阶段和最终阶段的设置。仓库中的原始脚本未被擅自改为其他分析方法。
